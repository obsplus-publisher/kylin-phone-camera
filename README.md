手里那台手机，画质通常比电脑上几百块的外接摄像头好得多。
不用买设备、不用装 App，把它接到电脑上，就是一路能直接进 OBS 的高清摄像头。

## 核心功能

| 能力 | 说明 |
| --- | --- |
| **扫码即连** | 电脑端显示二维码，手机扫码授权摄像头即可，手机不装任何 App |
| **虚拟摄像头** | 连接后在 OBS、直播工具、会议软件里当成普通摄像头直接选 |
| **镜头可控** | 分辨率、帧率、镜像、曝光、变焦、白平衡在电脑或手机上都能调 |
| **声音可传** | 手机麦克风可作为虚拟麦克风使用，画面和声音一起进电脑 |

## 支持的设备

| 平台 | 覆盖范围 |
| --- | --- |
| **安卓** | Android 手机与平板 |
| **苹果** | iPhone 与 iPad |
| **鸿蒙** | HarmonyOS 手机与平板 |
| **其他** | 平板取景；也支持连接其他电脑的摄像头 |

手机端走浏览器，不区分机型和系统版本，能打开浏览器的设备基本都能用。

## 三步上手

**1. 电脑装好并打开软件**

下载安装包，装完打开「麒麟高清手机摄像头」，点「开始接收」，界面会出现二维码。

**2. 手机扫码连接**
<img width="855" height="790" alt="扫码连接" src="https://github.com/user-attachments/assets/14e901d2-7f02-464d-9ddf-7b40ae237938" />

用手机微信、系统相机或任意扫码工具扫这个二维码，浏览器里允许摄像头权限，画面就过来了。

> 不需要在手机上装 App，也不需要手机和电脑登同一个账号——只要在同一个局域网里。

**3. 在 OBS / 直播伴侣 / 会议软件里使用**
<img width="821" height="704" alt="obs添加摄像头" src="https://github.com/user-attachments/assets/8eba1dd4-9679-4615-8191-bd903cd06c74" />

添加「视频采集设备」，设备列表里选「麒麟高清手机摄像头」，手机画面直接作为摄像头输入。

## 画面能力

不是简单投屏，而是一套完整的摄像头工作流：手机负责拍摄，电脑负责直播与制作。

| 项目 | 说明 |
| --- | --- |
| **分辨率与帧率** | 常用竖屏、横屏参数可选，如 1080 × 1920 · 30 FPS |
| **镜像与翻转** | 前后镜头分别保存显示习惯，切换不用重设 |
| **横竖屏** | 竖屏直播原生支持，不用后期旋转裁切 |
| **断开保护** | 意外断开时按「暂时离开 / 意外断开」显示，手机恢复后画面自动回来 |
| **流畅优先** | 网络或编码压力增大时，优先降低帧率保住流畅度 |

## 画面在局域网里走

| 环节 | 做什么 |
| --- | --- |
| **① 手机** | 浏览器打开扫码页，调用手机摄像头拍摄，不装 App |
| **② 局域网** | 同一 WiFi 或同一路由器下的有线网络，两端直连 |
| **③ 电脑** | 客户端接收画面，注册成一路虚拟摄像头 |
| **④ 软件** | OBS、直播伴侣、会议软件里直接选这个设备 |

**手机 → 局域网 → 电脑 → 直播软件**，四步走完，中间不经过第三方服务器。

手机与电脑之间直接传输画面，不需要先把实时画面上传到第三方云端再转回来：
<img width="3136" height="1344" alt="local-first" src="https://github.com/user-attachments/assets/c4a415b5-6c33-4a6f-8261-0b61a7f6f807" />
- **不上云**：少一层网络中转，延迟更低，也不用担心画面经过别人服务器
- **不装 App**：手机端是浏览器页面，扫完即用，不占存储
- **不改网络**：走的是现有局域网，不需要公网 IP 或端口映射

## 声音

需要时打开声音传输，把手机麦克风送到电脑。

| 输出方式 | 说明 |
| --- | --- |
| **传输声音** | 手机麦克风 → 电脑，画面和声音同步 |
| **虚拟麦克风**（推荐） | 在直播或其他接收声音的软件里直接选这个设备 |
| **桌面音频** | 从电脑扬声器 / 耳机播放 |

- 声音默认关闭，需要时手动开启
- 音量、波形、设备状态在软件里直接看得到

## 镜头参数

对焦、白平衡、色温、ISO、曝光、变焦都可以调，手机和电脑两端都能操作；切换前后镜头时，各自的设置互不干扰。

| 参数 | 常用取值 |
| --- | --- |
| **变焦** | 1.0× – 2.4× |
| **曝光** | -2.0 – +2.0 |
| **ISO** | 自动 / 手动 |
| **色温** | 约 5200K 起，按环境调 |
| **自动对焦** | 固定机位建议开，近距离展示建议关 |
| **镜像 / 翻转** | 前后镜头分别保存 |

实际可调范围取决于手机硬件和浏览器能力，部分参数在个别机型上不可用属正常现象。

## 在你已经熟悉的软件里继续用

装好虚拟摄像头之后，任何支持摄像头输入的软件都能按普通摄像头的方式接入：

| 软件 | 用法 |
| --- | --- |
| **OBS** | 添加「视频采集设备」，用于直播与录制 |
| **直播软件** | 作为摄像头输入使用 |
| **视频会议** | 同时作为摄像头和麦克风来源 |

原有的场景、推流设置、快捷键都不用改，只是多了一个画面更好的摄像头来源。

## 常见问题

<details>
<summary><b>手机需要安装 App 吗？</b></summary>

不需要。手机用浏览器扫描电脑软件里的二维码，授权摄像头权限后即可连接，用完关掉页面就行。
</details>

<details>
<summary><b>画面会上传到云端吗？</b></summary>

不会。实时画面在手机与电脑之间通过局域网直接传输，不需要把视频画面上传到第三方云端再中转。
</details>

<details>
<summary><b>为什么某些分辨率或帧率选不了？</b></summary>

实际可用参数取决于手机硬件、系统浏览器和当前摄像头的支持能力。选择过高参数时，浏览器可能无法提供对应的分辨率与帧率组合。
</details>

<details>
<summary><b>手机突然断开后会怎样？</b></summary>

已经正常连接过的画面如果意外断开，会按「暂时离开 / 意外断开」的显示设置处理；手机恢复连接后，实时画面会自动接回来，不用重新添加设备。
</details>

<details>
<summary><b>可以只把手机当麦克风用吗？</b></summary>

可以。声音功能与画面接收相互独立，单独开启声音传输即可。使用虚拟麦克风时，建议在目标软件里明确选择对应的虚拟麦克风设备。
</details>

<details>
<summary><b>手机和电脑必须连同一个网络吗？</b></summary>

是。两端需要在同一个局域网内（同一路由器下的 WiFi，或电脑走有线、手机走同一路由的 WiFi），这样才能直连，也不需要公网 IP。
</details>
